02

Rules, not hunches.

Pick a rule-based strategy such as a Donchian breakout, regular buying, a grid or a trailing stop. Each one is a short set of rules you can read.

03

Describe it in one line.

Type a trade the way you would say it: long MON, short BTC, 2x, $100, stop 8%. The agent drafts a strategy card with the legs, the stop and the risk checks. It only drafts. You approve every trade.

DEVELOPER INFRASTRUCTURE

Read the same markets.
Keep your own keys.

Every bin is built from Perpl's on-chain market data, so each leg, weight and price is visible before you enter. OpenCash never receives a private key.

View integration overview +

Market data is read straight from the Perpl exchange contract. Orders go to the same contract, sized to a whole lot before they are signed.
